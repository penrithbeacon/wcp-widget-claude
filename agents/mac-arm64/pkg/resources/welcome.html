WCP Claude Analytics — Host Agent

This installer will set up the Claude Analytics host agent as a Menu Bar Extra on your Mac. You'll see a small icon in your menu bar that shows the agent is running and gives you full control.

What will be installed:

  • WCP Claude Agent.app in /Applications — the menu bar agent
  • Uninstall WCP Claude Agent.app in /Applications — to remove the agent later
  • A launchd service for auto-start on login

What the agent does:

  • Provides local Claude Code data to the Claude Analytics widget
  • Reads your MCP server configuration, installed plugins, and recent sessions
  • Runs on localhost:3747 (not accessible from the network)

After installation:

  • Look for the agent icon in your menu bar (top-right of screen)
  • Click it to see status, change port, view logs, or uninstall
  • The agent starts automatically when you log in
Port conflict? If port 3747 is already in use, the menu bar icon will show a warning. Click it and select "Change Port…" to choose a different port.
