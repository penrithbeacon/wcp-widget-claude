Installation Complete

The WCP Claude Agent is now running in your menu bar.

Find it in your menu bar:

Look for the ● icon in the top-right of your screen, near the clock and Wi-Fi icons. Click it to see the agent menu.

Connect to your dashboard:

Open the Claude Analytics widget Settings instrument and click Test next to the Agent URL field. You should see "Connected — agent is running".

Control the agent:

Click the menu bar icon to:

  • See the current port and status
  • Change the port if there's a conflict
  • View logs, restart, or stop the agent
  • Toggle auto-start on login
  • Uninstall completely

To uninstall later:

Click the menu bar icon → Uninstall…, or open Uninstall WCP Claude Agent from your Applications folder.
