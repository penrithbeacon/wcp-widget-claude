📖 Help — Claude Analytics Widget

Getting Started

The Claude Analytics widget has two data sources:

  • Host Agent — a Menu Bar Extra that runs on your Mac, providing local Claude Code data (MCP servers, plugins, sessions, system info). Required for the Local: Environment and Local: Sessions instruments.
  • Anthropic Admin API (Alpha) — cloud-based usage reports and cost data. Required for the API: Usage and API: Productivity instruments. Requires an Admin API key which is not available on all account types.

To get started, download and install the host agent from the Settings instrument, then add the Local: Environment and Local: Sessions instruments to your dashboard.

Installing the Host Agent

  • Open the Settings instrument
  • Click Download .pkg under macOS (Apple Silicon)
  • Double-click the downloaded WCP-Claude-Agent.pkg
  • Follow the installer wizard (requires admin password)
  • After installation, look for the agent icon in your menu bar (top-right of screen, near clock/Wi-Fi)
The agent icon in your menu bar gives you full control: see status, change port, view logs, restart, stop, toggle auto-start, and uninstall.

Port Configuration

The agent runs on localhost:3747 by default. If this port is already in use:

  • The menu bar icon will show a warning (red indicator)
  • Click the icon → select Change Port…
  • Enter a new port number (1024–65535) and click Save & Restart
  • Important: After changing the port, update the Agent URL in the Settings instrument to match (e.g. http://host.docker.internal:3748)

Troubleshooting

  • Agent not connecting: Click the menu bar icon to check status. If stopped, click Start Agent. Verify the agent URL in Settings matches the port shown in the menu bar.
  • Port conflict: Use Change Port… from the menu bar to pick a different port, then update the URL in Settings.
  • No data showing: Click Test in Settings to verify connectivity. Check the menu bar icon is showing a green indicator.
  • Reinstalling: Uninstall first (see below), then download and install the .pkg again from Settings.

Uninstalling

Two ways to uninstall:

  • Click the agent's menu bar icon → select Uninstall…
  • Open Uninstall WCP Claude Agent from your Applications folder

Both methods completely remove the agent service, application, configuration, and logs.

Compatibility

The host agent reads Claude Code's local session and configuration files. We recommend keeping both Claude Code and this agent updated to their latest versions to ensure compatibility.

If the agent stops reporting data correctly after a Claude Code update, check for a new version of the agent in the Settings instrument.
